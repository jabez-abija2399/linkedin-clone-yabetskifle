# LinkedIn Clone – Yabetskifle

A Next.js-powered LinkedIn clone project showcasing modern full-stack development with real-time features and social networking capabilities.

---

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### 2. Run the Development Server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

### Milestone 1: Core Social Features 🤝

- **Connections System**

  - "People you may know" suggestions
  - Filter feed to show only connections' posts

- **Notifications** 🔔
  - Real-time alerts for likes and comments

  - Recent searches history
